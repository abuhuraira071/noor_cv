# MD Rashed-Uzzaman Noor — Portfolio

Professional portfolio website for **MD Rashed-Uzzaman Noor** — Biomedical Signal Processing & Edge AI Researcher, B.Sc. EEE (RUET).

Built with **React + Vite + Tailwind CSS v4 + Framer Motion**.

## Features
- Animated hero with live ECG SVG (Framer Motion pathLength)
- Scroll progress bar, parallax & staggered reveals
- Expandable research experience (MSFT-Net, Artemis monitor, MSCT-SEGFNet diffusion, EEG seizure/ADHD, CWT)
- Publications, Skills, Education timeline, Contact
- Dark medical-tech aesthetic (cyan/violet), fully responsive

## Run locally
```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview  # preview production build
```

## Stack
- `react@19`, `framer-motion@13`, `lucide-react`, `tailwindcss@4` (`@tailwindcss/vite`)
